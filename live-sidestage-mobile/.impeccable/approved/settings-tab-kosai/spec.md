# 光彩(Kosai) — 設定タブ 採用spec

採用元: `mobile-kosai-other-tabs.html` 方向A の3枚目(`comp.png`)と4枚目(`comp-sheet.png`)の
`.phone`。共通トークン・換算規則は `../_kosai-tokens.md` を正本とする。

comp caption:
> 設定 — 実装済みの機能(表示/読み上げ/効果音/アカウント)を全復元した上で、プランは課金画面と
> 同じ二重枠グラデーションカードとして独立させ視覚的なアクセントに。他の項目は白カードで
> グルーピングし密度を優先
> 設定 — 音量/速度の行をタップすると下からシートで開き、この中でだけスライダーを操作する
> (一覧はxx%表記+›に統一し単調さを解消)

## 共通部品

- **セクション見出し**(comp `.sec-title.grad`): グラデ文字22dp w700、
  padding 横16dp・上16dp・下8dp
- **パネル**(comp `.panel.soft`): 背景 card / 角丸18dp / 左右margin 16dp / 枠線なし /
  影 `rgba(155,107,255,.12)` blur22 offset(0,8) spread -18。行間は 1dp divider `#F1EBEE`
- **設定行**(comp `.switch-row`): 高さ最小52dp、padding 縦13dp・横14dp、左右両端寄せ
  - ラベル 13.5dp w500 ink。副文言(comp `.switch-row .sub`)は 11dp sub、上1dp
  - 右のスイッチ: トラック43×24dp / 角丸999 / ON=c2・OFF=`#E5DFE8` / つまみ白19dp / 枠なし
  - 右の値+`›`: 値 13.5dp、`Icons.chevron_right` 18dp。gap 4dp
    - **数値設定(音量・速さ)は c2 w700**、選択肢(テーマ・ボイス等)は sub w400

## 値設定ボトムシート(comp-sheet.png)

comp `.phone` 4枚目。`showModalBottomSheet` で開く。

- 背景 card / 上角丸20dp / padding 上20dp・横18dp・下26dp
- グラブハンドル: 幅40dp・高さ4dp・角丸2dp・色 `#E5DFE8`、中央、下margin 18dp
- 1行目(両端寄せ): 左にタイトル 15dp w700 ink / 右に現在値 18dp w800 **`gradScore` グラデ文字**
- スライダー(comp `.mini-slider`): 上margin 18dp
  - トラック高さ5dp / 角丸2.5dp / 有効部 c2 / 無効部 `#E5DFE8`
  - つまみ 直径16dp 白・枠2dp c2・影 `rgba(0,0,0,.2)` blur4 offset(0,1)
  - オーバーレイ半径 20dp、色 `c2 @0.12`
- ドラッグ中は手元の値で追従し、**指を離したときにだけ永続化する**(既存 `_VolumeSlider` の
  挙動をそのまま持ち込む。onChangedごとの保存はしない)
- 範囲: 音量0〜100(divisions 20) / 速さ50〜200%(divisions 30) /
  しきい値0〜1000コイン(divisions 20)
- 閉じ方: 外側タップ・下スワイプ(既定)。確定ボタンは置かない(値は即時反映)

## 状態

- ロック(FREEで速さ・ランダムボイス): 行は出したまま。**押下は禁止せず**アップグレード導線
- busy(開始/停止の遷移中): すべての編集行を無効化(既存 `canEdit` を維持)
- comp未定義: loading / error → 該当なし(設定はローカル状態のみ)

## 省略の既定

ゼロ。既存の全項目(テーマ・ランダムボイス・ボイス・読み上げ音量・読み上げ速さ・効果音音量・
TikTok ID・プラン導線・アカウント・VOICEVOX利用規約・ログアウト・アカウント削除・
プライバシーポリシー・反映中表示)を残す。しきい値設定のみ新規追加。
