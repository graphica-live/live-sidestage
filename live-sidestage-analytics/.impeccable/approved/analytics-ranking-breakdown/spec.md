基準画像: `comp.png`（1000px viewport / Light 上段・Dark 下段）

---

## 1. 構造（トポロジー）

ranking テーブルの各ユーザー行の**直後**に、開いているときだけ内訳行を1本差し込む。

```
<tr> ユーザー行（既存5列 + 新設チェブロン列 = 6列）
<tr> 内訳行（開いているときのみ）  → <td colSpan=6> → パネル
```

- **同時に開けるのは1行だけ**（既存 `openBattleId` と同じ単一 state パターン）。
- 内訳行はモーダルではない。テーブル内に留まり、周囲の行は動かない（下へ押し出すだけ）。

## 7. 情報密度

- ギフト1行 = **3情報**（アイコン+ギフト名 / 回数 / コイン数）。減らさない。
- レイアウト: `sm` 以上 **2カラム**グリッド、`sm` 未満 **1カラム**。
- 並び順: `totalDiamonds` 降順。読み順は左→右→次行。
- 区切り: ギフト行ごとに 1px 下罫（`border-row-border`）。カード化しない・ネストカードにしない。
- パネル見出しは1行に「ギフト内訳」+ 要約（種類数 · 回数 · コイン合計）、右端に期間注記（該当時のみ）。

---

## 8. 視覚階層

1. **最も目立つ**: 各ギフト行の右端コイン数（mono 700 / `text-strong`）
2. 2番目: ギフト名（`text-strong` 400）とギフト画像
3. 3番目: 回数（mono / `text-muted`）
4. 最も弱い: パネル見出しと要約（`0.68rem` / `text-muted`）

パネル全体はユーザー行より**弱い**。ランキングの読み取りを妨げないこと。

## 9. 要素インベントリ（全列挙・省略の既定はゼロ）

### ユーザー行（既存 + 追加）
| 要素 | 出典 | 備考 |
| --- | --- | --- |
| 順位 / アバター / ニックネーム / @uniqueId / 外部リンクアイコン / コイン数 / ギフト数 / 最終 | 既存 `GiftUser` | **変更しない** |
| **チェブロンボタン（新）** | — | 最終列の右。`aria-expanded` / `aria-controls` を持つ実 `<button>` |

### 内訳パネル
| 要素 | 出典フィールド |
| --- | --- |
| 見出し「ギフト内訳」 | 固定文言 |
| 要約「N種類 · M回 · X」 | `gifts.length` / `Σ repeatCount` / `Σ totalDiamonds` |
| 期間注記「YYYY-MM-DD 以降のみ」 | API `coverage.rawFrom`（部分カバー時のみ表示） |
| ギフト画像 | `gifts[].giftPictureUrl`（null ならプレースホルダ矩形） |
| ギフト名 | `gifts[].giftName`（`TiktokGiftCatalog.labelJa` 優先、無ければ受信名） |
| 回数「×N」 | `gifts[].repeatCount` |
| コイン数 | `gifts[].totalDiamonds` |

### インタラクション
| 操作 | 挙動 |
| --- | --- |
| ユーザー行のクリック/タップ | その行の内訳を開く。既に開いていれば閉じる。別行を開くと前の行は閉じる |
| チェブロンボタンのクリック | 同上 |
| チェブロンに `Enter` / `Space` | 同上（`<button>` の既定動作） |
| 行内の TikTok プロフィールリンク（3箇所） | 新規タブで TikTok へ。**展開はトリガしない**（`stopPropagation`） |
| 初回展開 | API を fetch。2回目以降は同一期間内はキャッシュから即描画（再fetchしない） |
| 期間/範囲の変更 | キャッシュを破棄し、開いていた行も閉じる |
| チェブロンの回転 | 閉 0° → 開 180°、`transition 160ms ease-out` |
| パネルの出現 | opacity 0→1 + translateY 4px→0、`160ms ease-out`。`prefers-reduced-motion: reduce` では無効 |

### 状態（comp.png に描かれているもの）
| 状態 | 表示 |
| --- | --- |
| loading | スケルトン3本（幅 78% / 60% / 69%）。スピナーは使わない |
| データあり | 2カラム（sm未満1カラム）のギフト行一覧 |
| 部分カバー | データありの表示 + 右端に「YYYY-MM-DD 以降のみ」注記 |
| 内訳なし（90日超・ロールアップのみ） | 「この期間の内訳は残っていません」/「ギフト明細は90日で削除されます。合計コイン数は集計から表示しています。」 |
| 空（内訳0件） | 「この期間の内訳はありません」（1行、`text-muted`） |
| error | 「内訳を取得できませんでした」/「通信に失敗しました。」+ 再試行ボタン |

### comp に描かれていない = **未定義**
- ギフト種類が極端に多い場合（50種以上）のスクロール/省略挙動 → 未定義。実装は全件表示とする
- パネル内の並び替え・フィルタ → 未定義（実装しない）
- CSV エクスポートへの内訳反映 → 未定義（実装しない）

## 10. 画像素材の要否

**該当なし。** 新規の画像・イラスト・アイコンアセットは不要。

- ギフト画像は TikTok 由来の `giftPictureUrl`（既存のギフト履歴タブと同じ扱い）
- チェブロンは authored inline SVG（既存 `ExternalLinkIcon` と同じ stroke-width 2 / linecap round に揃える）
- 絵文字をアイコンとして新規追加しない（既存ヘッダーの 💎🎁 はそのまま残す）
